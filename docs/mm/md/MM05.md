## Decisiones Tomadas

- Se valida el núcleo funcional desarrollado hasta el momento, incluyendo preguntas paramétricas, analíticas básicas, exportación CSV, historial del alumno y detalle de intento.
- Se acuerda no reabrir funcionalidad ya validada salvo que aparezca un error real durante la revisión posterior.
- Se acepta abrir un bloque opcional de cierre fino orientado a seguridad, ownership, grupos, simulación de cuestionarios, UX y mejora de cobertura de pruebas.
- Se mantiene el criterio de trabajar con pruebas por archivo nuevo y de corregir las pruebas existentes cuando un refactor modifique contratos o responsabilidades.
- Se acuerda que el proyecto debe seguir manteniendo trazabilidad mediante GitHub, ramas, issues y documentación actualizada.
