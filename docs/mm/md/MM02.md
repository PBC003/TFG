## Decisiones Tomadas
- Se valida el MVP planteado.
- Se valida la planificación general, con la corrección de no presentar la metodología como "Scrum" en sentido estricto, sino como un enfoque **basado en Scrum** o **Scrum-inspired**, al tratarse de un proyecto individual.
- Se validan los ADRs preparados.
- Se validan los casos de uso y los requisitos, sin necesidad de cambios grandes.
- Se valida la comparativa de alternativas realizada.
- El presupuesto queda validado.
- Se acuerda que los tipos de pregunta a considerar para el sistema serán, por ahora:
  - Verdadero/Falso.
  - Elección múltiple con una única respuesta correcta.
  - Respuesta corta auto orregible.
  - Respuesta corta revisable manualmente por el profesor.
- Se acuerda que no es necesario incorporar un motor matemático avanzado.
- Se considera suficiente el uso de **KaTeX** para representar notación matemática de Cálculo.
- Se confirma el modelo inicial de roles: **Admin**, **Teacher** y **Student**.
- Se acepta como mecanismo inicial de acceso el uso de **email universitario + contraseña**.
- Se confirma que el rol **Admin** podrá gestionar cuentas y modificar roles de usuario.
- Se acepta el acceso a cuestionarios mediante **códigos**.
- Se acepta el uso de **etiquetas/tags** para dejar preparada la evolución futura a varias asignaturas.
