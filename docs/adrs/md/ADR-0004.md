## Context
El profesorado debe poder redactar enunciados con notación matemática usando sintaxis LaTeX y el alumnado debe visualizarla correctamente en la interfaz web.

El objetivo es renderizar expresiones matemáticas en contexto de enunciados (no compilar documentos LaTeX completos), manteniendo rendimiento, simplicidad y compatibilidad con Docker.

### Alternatives considered
- MathJax: Es la más utilizada para mostrar matemáticas en la web. Ofrece la mayor compatibilidad con LaTeX, pero es una herramienta mucho más pesada, lo que ralentiza la carga de la página y resulta en un peor rendimiento percibido por el usuario.
- Compilación de LaTeX en el servidor (Backend a PDF/Imagen): Implicaría instalar distribuciones completas (como texlive) en el backend para transformar el código en imágenes de las fórmulas. Esta opción se descarta porque es un proceso muy costoso a nivel de recursos.
- KaTeX: Es una librería de renderizado matemático (desarrollada por Khan Academy) extremadamente rápida. Aunque no soporta todo LaTeX, es más que suficiente para el subconjunto de matemáticas que se utiliza en los cuestionarios de Cálculo.

## Decision
Los enunciados de las preguntas se guardarán en la base de datos como texto en formato Markdown, incluyendo soporte nativo para notación matemática mediante los delimitadores estándar (como "\ ( ... \ )" para fórmulas insertadas en la misma línea de texto, y "$$...$$" para fórmulas en bloque separadas). Este texto será procesado directamente en el navegador del usuario (frontend) utilizando la librería KaTeX.

## Consequences
Pros:
- El renderizado se ejecuta en el cliente (el navegador), por lo que es muy rápido y visualmente consistente.
- El servidor se mantiene ligero y fácil de empaquetar en Docker, al no requerir la instalación de texlive ni ejecutar procesos de compilación en el backend.
- La integración de KaTeX con el ecosistema de React (elegido en el ADR-0001) es muy sencilla y madura

Contras / riesgos:
- Al ser una librería optimizada para la web, no cubre el estándar de LaTeX al completo ni soporta ciertos paquetes avanzados (como utilidades de dibujo geométrico).
- Exige definir, acotar y documentar claramente qué subconjunto de comandos matemáticos están soportados por la plataforma.

## Compliance
- Se documentará formalmente el estándar de redacción esperado en la plataforma, combinando el uso de Markdown y los delimitadores de matemáticas.
- Se desarrollará un editor de preguntas.
- Se creará una batería de pruebas integrando un conjunto representativo de fórmulas de Cálculo complejas (límites, integrales, matrices) para garantizar la compatibilidad del sistema.
